# Automatic window interpretations

The opening schedule now proposes a window role when an SH or FX printed tag has a compatible measured wall gap and corroborating native frame/glazing strokes. This is an estimating interpretation requiring review. It does not establish operation, individual unit count, mulling, product selection, performance or manufacturer rough openings.

The current rule requires an orthogonal gap within one inch of nominal width, two inset glazing lines, and transverse jamb strokes at both pane ends and both outer gap ends. It accepts visible solid native line strokes only. Duplicate identical strokes do not create extra windows; distinct competing glazing pairs remain ambiguous. Bare tags, unsupported codes, missing jambs and incompatible widths remain unresolved. The tolerances are recognition heuristics, not building-code specifications.

Evidence includes the plan hash, current opening source hash, gap coordinates, scale, printed tag and native line references. Current reviewed windows retain their explicit unit counts. Conflicting current reviews are withheld with their previous values retained as evidence; stale reviews are not replaced. Measurement changes recompute interpretation from current evidence.

Window footprints can close candidate room boundaries, explicitly as hypotheses. They add no framing, floor finish or purchase quantities. Inferred roles reach the unsent opening bid draft with verification questions and unknown individual-unit counts. J&J bills window installation per individual unit, so a located window opening alone cannot price that installation.
